# Freelance Landing Page

A single-page site introducing my freelance web development services: skills, recent projects, what I can build and how to get in touch. Written in **vanilla HTML, CSS and JavaScript** and shipped as an installable **PWA**. The interface is Persian and right-to-left.

## What's inside

- Services: landing pages, simple online stores, PWAs, corporate sites, admin panels, performance optimisation
- Project cards rendered from data
- Light and dark themes that follow the system preference and remember the user's choice
- Scroll-reveal animations with `IntersectionObserver`
- Web app manifest, maskable icons and a service worker for offline access

## Run locally

```bash
npx serve .
```
